၃။ Systemd Service (Background Service) ဖန်တီးခြင်း
     FastAPI အမြဲတမ်း နောက်ကွယ်မှာ အလုပ်လုပ်နေစေရန် Systemd Service တစ်ခု ဖန်တီးရပါမည်။

     Bash
     sudo nano /etc/systemd/system/fastapi.service
     အောက်ပါ Content များကို ထည့်ပါ (your-user နဲ့ /path/to/your-project များကို သင့် Server အချက်အလက်များအတိုင်း ပြင်ပါ) -

     Ini, TOML
     [Unit]
     Description=FastAPI Application
     After=network.target

     [Service]
     User=your-user
     Group=www-data
     WorkingDirectory=/path/to/your-project
     ExecStart=/path/to/your-project/venv/bin/gunicorn -w 4 -k uvicorn.workers.UvicornWorker main:app --bind 127.0.0.1:8000

     [Install]
     WantedBy=multi-user.target
     Note: main:app နေရာတွင် သင်၏ entry point file အမည် (ဥပမာ main.py ဖြစ်ပါက main) နှင့် FastAPI instance နာမည် (app = FastAPI()) ကို စာလုံးပေါင်း မှန်အောင် ထည့်ပါ။

     Service ကို စတင်ပြီး Enable လုပ်ပါ -

     Bash
     sudo systemctl start fastapi
     sudo systemctl enable fastapi
     sudo systemctl status fastapi


5. Nginx Configuration ရေးခြင်း

Nginx က public request တွေကို လက်ခံပြီး 127.0.0.1:8000 ဆီ ပို့ပေးပါမယ်။ Uvicorn ကို public network ကနေ တိုက်ရိုက်ဝင်လို့မရအောင် localhost မှာပဲ bind ထားတာ ဖြစ်ပါတယ်။ 
Uvicorn
+1

Configuration file ဖွင့်ပါ။

sudo nano /etc/nginx/sites-available/fastapi

ဒီ configuration ကို ထည့်ပါ။


server {
    listen 80;
    server_name api.example.com;

    client_max_body_size 50M;

    location / {
        proxy_pass http://127.0.0.1:8000;

        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}

api.example.com နေရာမှာ ကိုယ့် Domain ကို အစားထိုးပါ။

Domain မရှိသေးဘဲ Server IP နဲ့ စမ်းချင်ရင် server_name ကို ဒီလို သတ်မှတ်နိုင်ပါတယ်။

server_name _;

သတိပြုရန် — client_max_body_size 50M က upload request ရဲ့ အများဆုံး body size ကို သတ်မှတ်တာပါ။ AI model အတွက် image upload လုပ်မယ်ဆိုရင် ကိုယ့်လိုအပ်ချက်အလိုက် ပြင်နိုင်ပါတယ်။

Site ကို enable လုပ်ပါ။

sudo ln -s /etc/nginx/sites-available/fastapi /etc/nginx/sites-enabled/fastapi

Default site နဲ့ configuration conflict ဖြစ်နေမှသာ လိုအပ်တဲ့ site ကို disable လုပ်ပါ။

sudo nginx -t

Configuration test အောင်မြင်ရင်—

sudo systemctl reload nginx

Mesh Warping / Displacing 



ဒီနည်းနဲ့လုပ်ဘယ်လိုလုပ်ရမှာလဲလို့။ fast api ကနေ depth map ထုတ်ပေးမယ်။ react frontend မှာ opencv နဲ့ tile ကပ်ထားတယ်

FastAPI ဘက်ကနေ Depth Anything ကိုသုံးပြီး Depth Map ထုတ်ပေးမယ်၊ React Frontend ဘက်မှာ OpenCV နဲ့ Tile ကပ်မယ်ဆိုတဲ့ Hybrid Architecture က စွမ်းဆောင်ရည်ပိုင်းရော၊ Real-time Texture Controls တွေ (Scale, Rotation, Grout) ကို React မှာ ဆက်သုံးလို့ရတာကြောင့် အကောင်းဆုံး ပုံစံဖြစ်ပါတယ်။

Mesh Warping / Displacing နည်းလမ်းကို ဒီစနစ်မှာ ဘယ်လို အကောင်အထည်ဖော်ရမလဲဆိုတာ တစ်ဆင့်ချင်း ရှင်းပြပေးပါမယ် -

၁။ FastAPI Backend ဘက်မှာ လုပ်ရမယ့်အလုပ် (Depth & Mesh Grid)
FastAPI က ပုံကိုလက်ခံရရှိတာနဲ့ Depth Anything နဲ့ နံရံရဲ့ 3D အစောင်းအကိုင်း (Mesh/Depth Gradient) ကို တွက်ထုတ်ပေးရပါမယ်။

Depth Map ထုတ်ခြင်း: Depth Anything V2 ကိုသုံးပြီး နံရံရဲ့ Depth Map (
Z-buffer) ကို ထုတ်ပါတယ်။

Dense Grid & Displacement တွက်ခြင်း:

နံရံဧရိယာပေါ်မှာ ကွက်စိပ်ဇယားကွက် (Grid Mesh - ဥပမာ 
20×20 ဇယားကွက်) တစ်ခုကို တည်ဆောက်ပါတယ်။

ဇယားကွက်ရဲ့ ထောင့်မှတ် (Vertices) တစ်ခုချင်းစီကို Depth Map ရဲ့ တန်ဖိုးနဲ့ တိုက်ပြီး ဘယ်လောက် တွန်းထုတ်ရမယ်/ဆွဲုံ့ရမယ် (Displacement) ဆိုတာကို NumPy နဲ့ တွက်ပါတယ်။

Response ပို့ပေးခြင်း:

အရင်ကလို ထောင့် ၄ ချက် (4 points) တည်း ပို့မယ့်အစား၊ အဲ့ဒီ စောင်းသွားတဲ့ ဇယားကွက်ရဲ့ Vertices တွေရဲ့ Coordinates အသစ်တွေ (သို့မဟုတ် OpenCV ရဲ့ map_x နဲ့ map_y remap matrices တွေကို) JSON format နဲ့ React ဘက်ကို ပြန်ပို့ပေးပါတယ်။

၂. React Frontend ဘက်မှာ OpenCV နဲ့ Tile ကပ်ခြင်း (cv.remap သို့မဟုတ် Mesh Warping)
React ဘက် (သင့်ရဲ့ လက်ရှိ applyProduct ဖန်ရှင်ထဲမှာ) က FastAPI ဆီကနေ အဲ့ဒီ Mesh Displacement data တွေကို လက်ခံရရှိပါတယ်။

လက်ရှိ ကုဒ်မှာ: cv.getPerspectiveTransform က ထောင့် ၄ ချက် (4 points) ကိုပဲ ယူပြီး ရိုးရိုး ပြားချပ်ချပ် Perspective လုပ်ပါတယ်။

2. FastAPI Backend Code ဥပမာ (Python)
FastAPI ဘက်မှာ Depth Anything နဲ့ Mesh တွက်ချက်ပြီး အထက်ပါ format တိုင်း ပြန်ထုတ်ပေးမယ့် ပုံစံပါ -

Python
from fastapi import FastAPI, UploadFile, File, Form
import numpy as np
import cv2

app = FastAPI()

@app.post("/api/mesh-warp-perspective")
async def mesh_warp_perspective(
    file: UploadFile = File(...),
    area_id: str = Form(...)
):
    contents = await file.read()
    nparr = np.frombuffer(contents, np.uint8)
    image = cv2.imdecode(nparr, cv2.IMREAD_COLOR)
    
    # 1. SAM 2 ဖြင့် နံရံ Mask ကို ဖြတ်ထုတ်ခြင်း
    # 2. Depth Anything V2 ဖြင့် Depth Map ထုတ်ခြင်း
    
    # 3. Grid Mesh တည်ဆောက်ပြီး Depth တန်ဖိုးဖြင့် Vertex Displacement တွက်ခြင်း
    rows, cols = 20, 20
    mesh_vertices = []
    
    # ဥပမာ - Grid တစ်ခုချင်းစီ၏ deformed coordinates များကို တွက်ထုတ်ခြင်း
    for r in range(rows):
        for c in range(cols):
            # Depth gradient နှင့် Slope ကိုအခြေခံ၍ x, y များကို တွက်ချက်သည်
            new_x = float(c * 20 + (r * 2)) # ဥပမာတွက်ချက်မှု
            new_y = float(r * 20 + (c * 1))
            mesh_vertices.append({"r": r, "c": c, "x": new_x, "y": new_y})

    return {
        "success": True,
        "area_id": area_id,
        "grid_shape": {"rows": rows, "cols": cols},
        "mesh_vertices": mesh_vertices
    }
